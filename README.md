PLP Python Week 8 — Python Toolkit
Introduction

The Python Toolkit is a menu-driven Python program created for the PLP Python Week 8 assignment. It demonstrates variables, input/output, conditionals, loops, lists, functions, and error handling.

Tools
Simple Calculator: Performs addition, subtraction, multiplication, and division.
To-Do List: Adds, displays, and removes tasks using a Python list.
Number Guessing Game: Challenges the user to guess a random number between 1 and 20 within five attempts.
Technologies Used
Python 3
Variables and data types
Input and output
If/elif/else statements
While and for loops
Lists and list methods
Functions and f-strings
How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project folder.
Run:
python toolkit.py


If necessary, use python3 toolkit.py.

Select a tool from the menu.
Choose option 4 to exit.

Reflection

The most challenging part of this project was making all three tools work correctly with the main menu. I had to understand how loops return control to the menu after each tool finishes. Handling invalid input was another important part of the assignment. Testing the calculator helped me understand why division by zero must be handled separately. Building the to-do list helped me learn how to add and remove items from a Python list. I also learned how conditionals can give users helpful feedback in the guessing game. With one more week, I would add file storage so that to-do tasks remain saved after the program closes.
